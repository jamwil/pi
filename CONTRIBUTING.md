# Contributing

This is a personal fork of [pi](https://github.com/earendil-works/pi-mono). It tracks upstream closely, so changes beyond the patchset described in the README usually belong upstream.

- Issues and pull requests are welcome at [jamwil/pi-mono](https://github.com/jamwil/pi-mono/issues). There is no contributor gate.
- Keep issues short, concrete, and reproducible.
- You must understand your code. AI-generated changes you cannot explain will be closed.
- Before submitting a PR, run `npm run check` and `./test.sh`; both must pass.
- Do not edit `CHANGELOG.md`.
- Agents working in this repository must follow `AGENTS.md`.
